大家好，我是 BlitzFair 团队的。今天这几分钟，我不演示抢票，我讲讲我们为什么要做这个。

过去一年，演唱会、球鞋、盲盒，所有限量发售都一样：开售那一刻，脚本一毫秒把名额打光，普通人连页面都没加载完，票就没了。加验证码、限购，只是抬高门槛，规则还是快者得。

我们问了一句：谁有资格买，能不能不由速度决定？我们的答案是，把资格从速度问题改成概率问题。

【打开网页端，指向页面】大家看这个页面，提交只交一个哈希，谁先谁后不影响结果；揭示之后进候选池；开奖一次洗牌定名单；没中签的一键退款，钱直接从合约回来，不经过平台。

【指向 Drop 状态】屏幕上这场已经跑完了，十五人下单、十五人揭示、十人中签，全在链上可查。

抽签管的是手速，管不了钱，多开地址照样按比例中，这条我们写在 README 里，不藏着。

接下来我放一段完整实录视频，网页端、模拟器、链上数据都在里面，大家跟着看就行。
